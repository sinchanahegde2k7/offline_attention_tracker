# Offline Attention Tracker

**Web-based offline attention tracking system** that monitors user interactions and visualizes attention patterns in real-time. Built for hackathon demo purposes.

---

## 🔹 Features

- **Front Page:** Attractive cover page with images, title, description, and “Start Tracking” button.  
- **Tracker Page:**  
  - Tracks **clicks, keyboard presses, mouse movement, idle time, and tab switching**.  
  - Displays **real-time interactive graph** of total attention activity.  
  - **Animated counters** for each type of interaction.  
  - **Interactive elements** (images/cards/buttons) that increase activity when clicked or hovered.  
- **Smooth Animations:** Graph updates smoothly, counters animate incrementally, cards/images hover effects.  
- **Responsive Design:** Works on desktops and smaller screens.  

---

## 🔹 Technologies Used

- HTML5  
- CSS3 (Flexbox, animations, gradients)  
- JavaScript (DOM events, setInterval, Chart.js)  
- Git & GitHub for version control
